# 🛡️ مستندات اسکنر اندپوینت‌های تمیز کلودفلر (Cloudflare Clean IP Scanner)

این سند نحوه عملکرد اسکنر اندپوینت‌های کلودفلر، مکانیزم دور زدن اختلالات اینترنت در ایران و نحوه اعمال آن روی کانفیگ‌های CDN را تشریح می‌کند.

---

## ۱. علت نیاز به اسکنر Clean IP در شبکه ایران

کانفیگ‌های مبتنی بر کلودفلر (مانند `VLESS WebSocket TLS`، `VLESS gRPC` یا `VMess WS`) از شبکه CDN کلودفلر به عنوان واسط (Reverse Proxy) استفاده می‌کنند.
دامنه کاربر (مثلاً `cdn.mysite.com`) از طریق دی‌ان‌اس به مجموعه‌ای از IPهای Anycast کلودفلر اشاره می‌کند.

در شبکه‌های همراه اول، ایرانسل و مخابرات:
1. بسیاری از رنج‌های آی‌پی پیش‌فرض کلودفلر مسدود یا دچار پکت‌لاس شدید (تا ۹۰٪) هستند.
2. با این حال، به دلیل وسعت عظیم شبکه کلودفلر (`AS13335`)، همیشه ساب‌نت‌هایی وجود دارند که در اپراتورهای خاصی بدون فیلتر و با پینگ زیر ۷۰ میلی‌ثانیه کار می‌کنند.

---

## ۲. ترفند جایگزینی IP با حفظ SNI (SNI Preservation)

برای دور زدن فیلترینگ، اپلیکیشن OstaApp از معماری زیر استفاده می‌کند:

```
[ کلاینت اندروید ]
       │
       ├─► مقصد اتصال سوکت TCP (Socket Connect Address): [ Clean Cloudflare IP (e.g. 104.16.132.229) ]
       │
       └─► بسته TLS ClientHello:
             ├── SNI Header  = cdn.mysite.com (دامنه اصلی کاربر)
             └── HTTP Host   = cdn.mysite.com
```

### مزایا:
- فیلترینگ بسته‌های ارسالی را به یک آی‌پی تمیز و بدون اختلال می‌بیند.
- سرور لبه کلودفلر بسته را دریافت کرده و به دلیل مقدار `SNI` و `Host` صحیح، آن را به سرور اصلی (Origin Server) کاربر تحویل می‌دهد.
- کاربر هیچ‌گونه خطای نامعتبر بودن گواهی SSL (`SSLHandshakeException`) دریافت نمی‌کند.

---

## ۳. نحوه تست زنده سوکت در اپلیکیشن

اسکنر اپلیکیشن OstaApp تست‌های ساختگی یا حدسی انجام **نمی‌دهد**؛ بلکه:
- یک سوکت TCP مستقیم روی پورت مشخص‌شده (`443`، `8443`، `2053`، `2083`، `2087` یا `2096`) باز می‌کند.
- دست‌تکانی TCP را دو بار پیاپی اجرا کرده و میانگین زمان میلی‌ثانیه (`RTT`) را می‌سنجد.
- در صورت بسته بودن یا رد شدن بسته (`Connection Refused / Timeout`)، مقدار `-1` ثبت شده و آن آی‌پی از لیست تمیزها خارج می‌شود.
